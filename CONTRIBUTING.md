# Contributing to Magento 2 MCP Bridge

Thank you for your interest in contributing to the **Magento 2 MCP Bridge**!

## How to Contribute
1. Fork the repository on GitHub.
2. Create a topic branch: `git checkout -b feature/my-new-feature`.
3. Follow Magento 2 Coding Standards and PSR-12.
4. Add automated PHPUnit tests for any new functionality in `Test/Unit/`.
5. Ensure all tests pass: `vendor/bin/phpunit -c phpunit.xml.dist`.
6. Submit a Pull Request.

## Security Disclosures
Please report any security vulnerabilities following our [Security Policy](SECURITY.md).
