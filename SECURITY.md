# Security Policy

## Reporting a Vulnerability

We take the security of Magento stores and AI integrations very seriously.

If you discover a security vulnerability within **PriyankJivani_McpBridge**, please **DO NOT** create a public issue.

Instead, please send an email with vulnerability details, reproduction steps, and impact assessment to:
📧 **priyankjivani48@gmail.com**

We will acknowledge receipt within 24 hours and provide an estimated timeline for remediation.
